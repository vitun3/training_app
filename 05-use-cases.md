# 5. Use Cases

## Primary Use Cases
- Register and authenticate.
- Create a workout plan.
- Log a completed session.
- Follow another user.
- Publish a social post.
- Receive a reminder notification.

## Actor Summary
- User
- Coach
- Admin

## Example Flow
1. A user signs in.
2. The user opens their dashboard.
3. The user creates a plan and logs a workout.
4. The system stores the data and updates progress metrics.
5. The user receives a notification for completion and social engagement updates.
