# 14.1 Функциональное представление

## 14.1.1 Назначение

Функциональное представление определяет основные функциональные блоки системы, их ответственность и взаимодействие.

Основой представления является декомпозиция системы по бизнес-доменам.

---

## 14.1.2 Основные функциональные компоненты

| Компонент | Основная ответственность |
|---|---|
| **Мобильное приложение** | Пользовательский интерфейс и взаимодействие с платформой |
| **API / Access Layer** | Приём запросов, маршрутизация и контроль доступа |
| **Сервис пользователей** | Профили, настройки и пользовательские данные |
| **Сервис тренировок** | Создание, выполнение и хранение тренировок |
| **Сервис устройств** | Подключение устройств и получение телеметрии |
| **Сервис аналитики** | Анализ результатов и спортивной активности |
| **Сервис рекомендаций** | Формирование персональных рекомендаций |
| **Сервис соревнований** | Соревнования, результаты и рейтинги |
| **Социальный сервис** | Группы, поиск пользователей и социальное взаимодействие |
| **Сервис инвентаря** | Управление спортивным оборудованием |
| **Сервис уведомлений** | Доставка уведомлений |
| **Интеграционный контур** | Взаимодействие с внешними системами |
| **Event Bus** | Асинхронная доставка бизнес-событий |

---

## 14.1.3 Функциональные группы

Для повышения понятности сервисы могут быть объединены в следующие функциональные группы.

### Пользовательский контур

- Пользователи;
- Профиль;
- Настройки;
- Аутентификация.

### Спортивный контур

- Тренировки;
- Спортивные устройства;
- Спортивный инвентарь;
- Аналитика.

### Социальный контур

- Спортсмены;
- Группы;
- Публикации;
- Совместные тренировки.

### Соревновательный контур

- Соревнования;
- Рейтинги;
- Достижения;
- Геймификация.

### Персонализационный контур

- Рекомендации;
- Промоакции;
- Спортивные новости.

### Интеграционный контур

- Спортивные устройства;
- Существующие приложения компании;
- Внешние системы.

---

## 14.1.4 Основные функциональные зависимости

Основной поток обработки спортивной активности:

```text
Спортивное устройство
        │
        ▼
Сервис устройств
        │
        ▼
Сервис тренировок
        │
        ▼
Event Bus
        │
        ├──────────────► Аналитика
        │                    │
        │                    ▼
        │              Рекомендации
        │
        ├──────────────► Соревнования
        │
        ├──────────────► Социальный сервис
        │
        └──────────────► Уведомления
```
